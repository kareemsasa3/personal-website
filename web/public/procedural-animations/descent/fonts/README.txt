IBMPlexSansVar-Roman-Latin1.woff2
  IBM Plex Sans Var 3.000, Roman, Latin1 split, unmodified from IBM's own
  release (github.com/IBM/plex, @ibm/plex-sans-variable@0.2.0,
  fonts/split/woff2), renamed without spaces. IBM Plex has the Reserved Font
  Name "Plex", so IBM's original file is used rather than a third-party
